HTML DOM Tree Explanation:

When I inspected the page using browser developer tools, I learned how HTML elements are organized as a tree structure.
The body element is the parent of all visible webpage content. The images section is a child element inside the body.
The figure element is a child of the images section. The image element is placed inside the figure element.
The figcaption element provides a description of the image.
